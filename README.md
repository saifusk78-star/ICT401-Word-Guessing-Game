## Description

This is an interactive word-guessing game developed in Python. It includes a command-line interface and a Tkinter graphical interface.

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Keep all files in the same folder.
4. Run `cli_app.py` for the command-line version.
5. Run `gui_app.py` for the graphical version.
6. Run `test_engine.py` to test the game engine.

No external Python packages are required.
